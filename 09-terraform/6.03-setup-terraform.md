# Setting-up Environment for Terraform

### Install Terraform (Manual)

- **Download the Binary**
  - Visit the official HashiCorp Terraform Download Page (https://developer.hashicorp.com/terraform/downloads) and select the Windows AMD64 version.
- **Extract the File**
  - Open the downloaded .zip file and extract terraform.exe.
  - It is recommended to create a dedicated folder, such as C:\terraform, and move the executable there.
- **Add Terraform to System PATH**
  - Search for **Edit the system environment variables** in the Windows Start menu
  - On the _System Properties_ window, select **Advanced** tab >> Click **Environment Variables** button.
  - Under **System variables** section >> find the `Path` variable and click **Edit** button.
  - Click **New** and paste the folder path where you saved Terraform (e.g., C:\terraform)

2. **Install Editor (Visual Studio Code)**
   - https://code.visualstudio.com/download
   - Install extensions: Hashicorp Terraform, Prettier

3. **Install Git**
   - https://git-scm.com/downloads
