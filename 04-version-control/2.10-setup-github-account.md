## 02. Lab: Integrate GitHub with local system (git)

### 2.1 Prerequisites

- Git
  - Before connecting to GitHub, you need the Git command-line tool installed locally on you Windows/Linux/MacOS machine.

### 2.2 Configure Your Global Git Identity

- Set your name and email address.
- Git attaches this information to every code change (commit) you make so others know who wrote the code.

- Launch terminal and run the following commands:

```bash
git config --global user.name "Your Name"

git config --global user.email "your_email@example.com"
```

📌 Best Practice - Use the exact same email address you used to sign up for your GitHub account so your commits link correctly to your online profile.

### 2.3 Set Up Secure SSH Authentication (Recommended)

You can use Personal Access Tokens (PATs) or SSH key based authentication which are the modern industry standard because they are tied to your specific machine and never expire.

- Launch terminal and run the following command:

```bash
# Generate a new SSH key
ssh-keygen -t ed25519 -C "your_email@example.com"
```

- Copy the public SSH key (located in your host directory/folder of your system) to your clipboard and upload it to your GitHub account.
  - Sign-in to you [GitHub](https://github.com) Account.
  - Click the **New SSH key** button &rarr; Give it a title (e.g., "My Windows Laptop").
  - Paste your copied key into the **Key** text field and click **Add SSH** key.

### 2.4 Test the connection

Run the following command on your local system's terminal:

```bash
ssh -T git@github.com

# If successful, you will see a message like: "Hi {username}! You've successfully authenticated..."
```
