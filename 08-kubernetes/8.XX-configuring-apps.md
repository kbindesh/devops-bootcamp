# Configuring Applications in Kubernetes

## 01. ConfigMaps

- ConfigMap is stores configuration data in key-value pairs.
- ConfigMaps can be used to configure the app running in a container by configuring a pod to consume ConfigMaps using:
  - Environment variables
  - Command-line arguments
  - Mounting a volume with configuration files

## 02. Create a `configMap`

- You can create a Kubernetes **ConfigMap** using either a _declarative YAML manifest_ file or _imperative kubectl CLI_ commands.

### Lab: Create a configMap using a YAML Manifest (Recommended)

- Create a manifest named _configmap.yml_ and add your configuration data under the data field

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-configmap
data:
  db_name: "salesOrder"
  db_port: "1433"
  LOG_FILE_LOC: "/var/lib/db/app.log"
  database.properties: |
    db.host=mysql-service
    db.port=3306
```

- Now create a _configMap_ by executing the above manifest file:

  ```
  kubectl apply -f configMap.yml
  ```

## 03. kubectl commands for _configMap_

### List all the configMaps

```
kubectl get configmap
or
kubectl get cm
```

### Describe a configMap

```
kubectl describe configMap <configmap_name>
```

### Delete a configMap

```
kubectl delete cm bin-configmap
```

## 04. Lab: Consume configuration stored in configMap into a Pod using `Environment Variable`

- Develop a manifest file _pod-consuming-configmap.yml_ for creating a Pod and consuming the above created configMap data into it:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: bin-configmap
spec:
  containers:
    - name: bin-container
      image: busybox
      command: ["sh", "-c", "echo $(MY_VAR) && sleep 3600"]
      env:
        - name: MY_VAR
          valueFrom:
            configMapKeyRef:
              name: app-configmap
              key: db_name
```

- Apply the above config file to create a Pod:

```bash
kubectl apply -f pod-consuming-configmap.yml
```

- You can use the following command to check the configMap value:

```bash
kubectl logs bin-configmap
```

## 05. Lab: Consume configMap data into a Pod using `Container Volumes`

- Develop a manifest file _pod-consuming-configmap.yml_ for creating a Pod and consuming the above created configMap data into it:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: bin-volume-pod
spec:
  containers:
    - name: myapp-container
      image: busybox
      command: ["sh", "-c", "echo $(cat /etc/config/db_name) && sleep 3600"]
      volumeMounts:
        - name: config-volume
          mountPath: /etc/config
          volumes:
            - name: config-volume
              configMap:
                name: bin-configmap
```

- Apply the above config file to create a Pod:

```bash
kubectl apply -f pod-consuming-configmap.yml
```

- You can use the _kubectl logs_ command to check the pod for the mounted data value, or use the following command to check the configmap:

```bash
kubectl exec bin-volume-pod -- ls /etc/config
```
