# Setup Kubernetes Cluster

## 01. Setup K8s Cluster using `minikube`

- `minikube` is local Kubernetes (single node) environment, focusing on making it easy to learn and develop k8s concepts.
- Not recommended for production.
- Official Documentation: https://minikube.sigs.k8s.io/docs/start/

- What you'll need is a machine with the following specs:
  - 2 CPUs or more
  - 2GB of free memory
  - 15GB of free disk space
  - Internet connection
  - Container or virtual machine manager, such as: Docker, QEMU, Hyperkit, Hyper-V, KVM, Parallels, Podman, VirtualBox, or VMware Fusion/Workstation

### Step-1.1: Create a VM or Amazon EC2 instance

- Navigate to AWS Management console &rarr; EC2 &rarr; Create Instance
- Name: Kubernetes
- AMI: Amazon Linux 2023
- Instance Type: <any_two_vcpu_instance_type> e.g t3.small/t3.medium
- Ingress: Allow SSH (22)
- Egress: Allow all
- VPC & Subnet: Default
- Key Pair: <create_a_new_keypair>
- Storage: 15GB or above (root)

### Step-1.2: Install and Configure `Docker Engine`

- Source: https://docs.docker.com/engine/install

- Connect to your VM/EC2 instance over the SSH and run the following commands:

```bash
# Install Docker on Amazon linux 2023
sudo dnf install -y docker

# Start the docker service
sudo systemctl start docker

# Enable the docker service
sudo systemctl enable docker

# Check the status of docker service
sudo systemctl status docker

# Add the ec2-user to docker group
sudo gpasswd -a ec2-user docker
OR
sudo usermod -a -G docker ec2-user

# Logout/shutdown and reconnect to your Docker host (IMP)
exit
OR
shutdown -r now
```

- Now, reconnect to your EC2 instance or VM over SSH and run the following docker commands to verify the installation without prefixing _sudo_ to it:

```bash
# Check installed version to Docker
docker --version
```

### Step-1.3: Install `kubectl` (CLI) utility

- Source: https://kubernetes.io/docs/tasks/tools/#kubectl
- `kubectl` is a utility to send instructions to manage a K8s cluster.

- It is required to install it before you configure or install the K8s cluster

```bash
 # Download the kubectl binary
 sudo curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"

 # Provide execute permission to kubectl
 sudo chmod +x kubectl

 # Move the kubectl program to /usr/local/bin in order to access it from any location
 sudo mv kubectl /usr/local/bin

 # To verify the kubectl installation
 kubectl version
```

### Step-1.4: Install and Configure `minikube`

- Source: https://minikube.sigs.k8s.io/docs/start
- After Docker and Kubectl are installed, run the following set of commands to install `minikube`:

```bash
# Download the minikube binary
sudo curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64

# Install the minikube in /usr/local/bin/ directory
sudo install minikube-linux-amd64 /usr/local/bin/minikube

# To verify the minikube installation
minikube version
```

### Step-1.5: Start the `minikube` cluster

```bash
 # Start the minikube cluster
 minikube start

 # You will see a set of messages appearing on the console

 # Check the minikube k8s status | should be in running state
 minikube status
```

### Step-1.6: Interact with your K8s cluster

- As your k8s cluster is running, you can access it:

```bash
# List pods present in default namespace
kubectl get pods

# Get the list of k8s cluster nodes | should see only one "minikube" | control plane
kubectl get nodes
```

- Your minikube cluster contains one node that serves as both the control plane and worker node.
- That means that once you have it set up, you can start to schedule workloads in your local Kubernetes cluster.
