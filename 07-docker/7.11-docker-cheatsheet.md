# Docker Cheat Sheet

This Docker cheat sheet covers everything from basic container management to _Dockerfile_ directives and volume configuration.

## 01. Container Lifecycle

```bash
# Create and Run a container in the background (detached mode), assign a name, and map host port 8080 to container port 80
docker container run -d --name $CONTAINER_NAME -p $HOST_PORT:$CONTAINER_PORT $IMAGE_NAME:$TAG

docker container run -dit --name webapp -p 4000:80 httpd:latest

# List all running Containers
docker ps
OR
docker container ls

# List all containers, including those that are stopped
docker ps -a
OR
docker container ls -a

# Start an existing, stopped container
docker container start $CONTAINER_NAME

# Gracefully stop a running container
docker container stop $CONTAINER_NAME

# Stop and immediately start a container
docker container restart $CONTAINER_NAME

# Delete a stopped container
docker rm $CONTAINER_NAME
OR
docker container rm $CONTAINER_NAME

# Force-delete a running container using SIGKILL
docker container rm -f $CONTAINER_NAME
```

## 02. Image Management

```bash
# Build an image from a Dockerfile located in the current directory and assign a tag
docker image build -t $IMAGE_NAME:$IMAGE_TAG .

# Force a rebuild of the image without using cached layers
docker image build --no-cache -t $IMAGE_NAME:$IMAGE_TAG .

# List all locally downloaded and built images
docker images
OR
docker image ls

# Remove a local image
docker rmi $IMAGE_NAME:$IMAGE_TAG
OR
docker image rm $IMAGE_NAME:$IMAGE_TAG

# Download an image from Docker Hub without running it
docker image pull $IMAGE_NAME:$IMAGE_TAG

# Upload a local image to Docker Hub Registry
docker image push $REGISTRY_USERNAME/$IMAGE_NAME:$IMAGE_TAG
```

## 03. Inspection and Debugging

```bash
# Stream live logs from a specific container
docker container logs -f $CONTAINER_NAME

# Open an interactive shell inside a running container (use bash if available)
docker container exec -it $CONTAINER_NAME /bin/sh
OR
docker container exec -it $CONTAINER_NAME /bin/bash

# Return low-level, detailed JSON configuration data of a container or image
docker container inspect $CONTAINER_NAME

# Display the running processes inside a container
docker container top $CONTAINER_NAME

# View real-time resource usage statistics (CPU, memory, network)
docker stats

# Copy files from your local machine into a container
docker container cp $HOST_PATH $CONTAINER_NAME:$PATH
```

## 04. Dockerfile Instructions/Directives

A Dockerfile handles image building using specific instructions:

- FROM
  - Sets the foundational base image for subsequent instructions.

- WORKDIR
  - Defines the working directory for any subsequent RUN, CMD, or COPY instructions.
- COPY <src> <dest>
  - Copies files or directories from your host machine into the container.
- RUN
  - Runs commands during the image build stage and commits the results.
- ENV
  - Establishes environment variables that persist during container runtime.
- EXPOSE
  - Documents the specific ports the container intends to listen on.
- ENTRYPOINT
  - Configures the default, un-overrideable executable command for the container.
- CMD
  - Provides default arguments for the ENTRYPOINT or a default runtime command.

## 05. Networking and Volumes

```bash
# Provision a persistent, named data volume managed by Docker
docker volume create $VOLUME_NAME

# Mount a named Docker volume to a specific container path
docker container run -v $VOLUME_NAME:$MOUNT_POINT $IMAGE_NAME

# Bind-mount a specific local directory into a container
docker container run -v $(pwd)/host_dir:/data $IMAGE_NAME

# Spin up a custom user-defined network bridge
docker network create --driver bridge $NETWORK_NAME

# Connect a new container to a designated network at startup
docker container run --network=$NETWORK_NAME $IMAGE_NAME
```

## 06. System Cleanup

```bash
# Wipe all stopped containers, unused networks, and dangling build caches
docker system prune

# Perform a deep clean to wipe all unused images, stopped containers, and volumes
docker system prune -a --volumes

# Wipe all stopped containers
docker container prune

# Remove all dangling and unreferenced images
docker image prune
```

## 07. Docker Compose

Compose handles multi-container orchestration using a local `docker-compose.yml` file.

```bash
# Build, create, and launch all services in detached background mode
docker compose up -d

# Stop and entirely remove all containers, networks, and volumes created by up
docker compose down

# Display the state of all services managed by the local configuration file
docker compose ps

# Tail live output streams from all orchestrated services simultaneously
docker compose logs -f
```
